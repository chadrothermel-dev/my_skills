# Carriers by Host Network

> **Last checked: 2026-11 from memory, not live.** Ownership, host networks, and lineups change often. Confirm each carrier still exists and which network it uses before including it. Prices are deliberately left out: always fetch them live.

## Network owners (the three national networks)
| Network | Postpaid brand | Notes |
| :--- | :--- | :--- |
| **Verizon** | Verizon (myPlan tiers, add-on perks) | Owns Visible, Total Wireless, Straight Talk, Tracfone brands |
| **AT&T** | AT&T Unlimited tiers | Owns Cricket |
| **T-Mobile** | T-Mobile Experience / Essentials tiers | Owns Metro, Mint. Absorbed UScellular's wireless customers (2025) |

Regional: **Boost Mobile** (EchoStar) runs its own network in some areas and roams on AT&T; its network plans changed in 2025, so check current status.

| Google Fi | T-Mobile | International travelers, Pixel users |

| Helium Mobile | T-Mobile + Helium hotspots | Ultra-low-cost, check coverage |

## How to use
1. Keep only brands whose host network passed the coverage filter.
2. For a family, check whether the MVNO prices per line or offers multi-line discounts.
3. MVNO data is often **deprioritized** behind postpaid customers. Fine for most users; flag it for heavy users in congested areas.
